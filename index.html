11 / Build with confidence

Make every layer
inspectable

Helpful commands turn an agent from a magic demo into a system you can understand, test, and extend.

Sunday Reportraw data → final message
  1. make dump-week DAY=...see raw weekly aggregates
  2. make facts DAY=...inspect five signals + verdict JSON
  3. make report-rawpreview deterministic Telegram output
  4. make reportcompare optional AI narration
  5. make verifyformat, vet, test, build, glossary
PaperdinkSVG → physical pixels
  1. make preview-p1open the exact SVG in Chrome
  2. /previewsee both pages + simulated 1-bit mode
  3. make curl-bmpverify 400 × 300 bitmap encoding
  4. make typecheckcatch Worker contract mistakes
  5. make flashship only after the browser path is right
Do not debug the whole agent at once. Make the source, facts, render, and delivery independently visible.
