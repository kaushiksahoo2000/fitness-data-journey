07 / Signals

What the agent
actually looks at

Each signal compares this week with my trailing six-week baseline, then reports a direction, magnitude, confidence, and plain-language explanation.

01

Load & ramp

Is longer-term fitness rising without fatigue getting away?

training load · fitness trend · form
02

Volume

How much work moved through the week?

moving time · total load · run distance
03

Intensity

How concentrated and hard was that work?

load per hour · pace · heart rate
04

Consistency

Did I keep showing up across the week?

active days · sessions · sport mix
05

Recovery

Does readiness support the training story?

HRV · resting HR · sleep · weight context

How it stays honest

Medians reduce the effect of one strange week. Missing inputs lower confidence and add a caveat—they never become a guess.

building holding recovering by design decline possible overreaching caution insufficient data

09 / In practice

The feedback loop
now closes itself

Live demo

Sunday asks for context, sends the verdict, and keeps enough history to make next Sunday better.

Catch-up: an interrupted Sunday run resumes without double-sending.

Durability: backfill builds baselines; daily WAL-safe backups rotate locally.

Self-alerting: stale data, build failures, or backup failures send one calm alert.
